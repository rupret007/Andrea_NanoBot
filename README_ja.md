# Andrea_NanoBot 日本語サマリー

Andrea_NanoBot は、NanoClaw の分離ランタイムを土台にした Andrea の実運用向けアシスタントです。

## 現在の要点

- Telegram が標準の会話フロントドアです
- `/cursor` は主要なオペレーター向けワークフローです
- Codex/OpenAI ランタイムは統合済みですが、`/runtime-*` は補助的な明示コマンドです
